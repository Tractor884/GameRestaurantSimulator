# Мини-сервис общего рейтинга игроков (порт 3001)

Небольшой Node-сервис без единой зависимости: общий рейтинг «среди друзей»
для статической версии игры на VPS. Фронтенд игры ходит по относительному
пути `/api/leaderboard`, nginx проксирует его на этот сервис — код игры
не меняется.

## API (контракт 1-в-1 с Next.js-версией `/api/leaderboard`)

| Метод | Путь               | Ответ                                        |
| ----- | ------------------ | -------------------------------------------- |
| GET   | `/api/leaderboard` | `{ "results": [...] }` — топ-50 (очки ↓)     |
| POST  | `/api/leaderboard` | `201 { "result": {...} }` / `400 { error }`  |
| GET   | `/api/health`      | `{ ok: true, entries, version, startedAt }`  |

POST-тело: `{ nick, restaurantName, level (A+…D−), score (0–1000),
difficulty (novice|standard|professional), weeksLived (1–52) }`.
Каждый финал — отдельная строка истории (как в основной версии).

## Хранение

JSON-файл `data/leaderboard.json` рядом со скриптом (создаётся сам).
Атомарная запись (tmp + rename), лимит 1000 записей, повреждённый файл
автоматически бэкапится как `*.broken-*` и сервис продолжает работу.

## Запуск

```bash
# песочница (авто-перезапуск при правках)
bun run dev

# любой сервер с Node.js 10+ (на VPS этим занимается systemd)
node index.js
```

Переменные окружения: `HOST` (по умолчанию `0.0.0.0`; на VPS systemd
задаёт `127.0.0.1` — наружу сервис не торчит, всё через nginx).

## Развёртывание на VPS

См. `deploy/INSTALL.md` в корне репозитория: systemd-юнит
`restsim-api.service` + nginx-конфиг с `proxy_pass /api/` → `127.0.0.1:3001`.
